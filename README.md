# 🗽 Jogo Nova York 3D - Tráfego Urbano (Web)

Este projeto simula o tráfego de carros e ônibus em Nova York em ambiente 3D, utilizando **HTML, CSS, JavaScript** e a biblioteca **Three.js**.  
O objetivo é demonstrar veículos fluindo pelas ruas com diferentes velocidades e comportamentos.

---

## 🚀 Tecnologias
- HTML5
- CSS3
- JavaScript (ES6+)
- [Three.js](https://threejs.org/) para renderização 3D

---

## 🎮 Funcionalidades
- Carros (cubos vermelhos) fluindo continuamente pelas ruas
- Ônibus (cubos azuis) fluindo mais lentamente e com paradas simuladas
- Estrada em 3D renderizada no navegador
- Compatível com **GitHub Pages** para rodar online
